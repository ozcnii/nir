# thesis/

Рабочая папка пояснительной записки ВКР. Пишем в Markdown, потом
конвертируем в `.docx` по требованиям СТО университета.

## Структура

```
thesis/
├── intro.md          — Введение
├── chapter1.md       — Глава 1. Описание и анализ предметной области
├── references.md     — Список использованных источников (сквозная нумерация)
├── screenshots/      — Скриншоты систем-аналогов для рисунков
└── README.md         — этот файл
```

## Соглашения по оформлению в MD

- Заголовки: `#` — глава, `##` — раздел 1.x, `###` — подраздел 1.x.y.
- Рисунки: подписи в формате `![Рисунок N — Название](screenshots/file.png)`,
  сквозная нумерация по всей работе.
- Таблицы: подпись **над** таблицей в формате `Таблица N — Название`.
- Ссылки на источники: `[N]` в тексте, сами источники — в
  `references.md` со сквозной нумерацией.
- Кавычки: русские «ёлочки».
- Тире: длинное «—» вокруг пробелов.
- Единицы измерения: неразрывный пробел (в MD — обычный, при конвертации
  заменится).

## Перенос в Word

### Ручной способ (быстро)
1. Открыть `chapter1.md` в VS Code или Obsidian.
2. Скопировать отрендеренный вид в Word.
3. Применить стили по СТО (шрифт Times New Roman 14 pt, интервал 1.5,
   отступ первой строки 1.25 см, поля 2/2/3/1 см).

### Автоматический способ через pandoc (рекомендуется)

Установка:
```sh
brew install pandoc
```

Шаг 1 — создать эталонный шаблон со стилями под СТО (один раз):
```sh
pandoc -o reference.docx --print-default-data-file reference.docx
# затем открыть reference.docx в Word, настроить стили
# (Normal, Heading 1/2/3, Caption, Table Caption) под требования СТО
# и сохранить.
```

Шаг 2 — сборка главы:
```sh
pandoc chapter1.md references.md \
  --from gfm \
  --to docx \
  --reference-doc=reference.docx \
  --output chapter1.docx
```

Шаг 3 (опционально) — автосборка всей работы:
```sh
pandoc intro.md chapter1.md chapter2.md chapter3.md conclusion.md references.md \
  --from gfm --to docx \
  --reference-doc=reference.docx \
  --toc --toc-depth=3 \
  --output thesis.docx
```

### Что потребуется доделать руками после pandoc
- Титульный лист и задание — вставить из шаблона кафедры отдельно.
- Нумерация страниц — начинается с «Введения» (обычно со стр. 10).
- Оглавление — вставить через Word («Ссылки → Оглавление»), а не
  `--toc` от pandoc (pandoc генерирует своё, не по ГОСТ).
- Подписи к рисункам/таблицам — проверить нумерацию, при необходимости
  перегенерировать через «Вставка → Перекрёстная ссылка».
- Формулы — если появятся, писать в MD через `$...$`, далее pandoc
  конвертирует в Office Math; проверить вручную.
