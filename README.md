# ВКР — «Разработка системы сбора и анализа объявлений о недвижимости на основе данных из нескольких источников»

Выпускная квалификационная работа бакалавра ФИИТ, Самарский
национальный исследовательский университет имени академика С. П. Королёва.

**Тема:** Разработка системы сбора и анализа объявлений о недвижимости
на основе данных из нескольких источников («Авито Недвижимость»,
«Циан», «Домклик»). Ключевой научный компонент — дедупликация
объявлений, агрегированных из нескольких независимых источников.

## Структура репозитория

```
nir/

│   ├── intro.md              — Введение

│   ├── references.md         — Список использованных источников
```
