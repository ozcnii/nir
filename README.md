# ВКР — «Разработка системы сбора и анализа объявлений о недвижимости на основе данных из нескольких источников»

Выпускная квалификационная работа бакалавра ФИИТ, Самарский
национальный исследовательский университет имени академика С. П. Королёва.

**Тема:** Разработка системы сбора и анализа объявлений о недвижимости
на основе данных из нескольких источников («Авито Недвижимость»,
«Циан», «Домклик»). Ключевой научный компонент — дедупликация
объявлений, агрегированных из нескольких независимых источников.

## Проектирование программы

Текущие согласованные материалы ВКР находятся в [bachelor-thesis/](bachelor-thesis/README.md). Пункты1–7 проектирования закрыты, далее8–9; приложение и экспериментальные результаты еще не созданы. НИР в `thesis/nir/` сохраняется как исторический исходный документ; текущие принятые решения, включая фотоURL-only, определяются документацией ВКР.

Название репозитория `nir` сохраняется; работа уже продолжается как ВКР в той же историиGit.

## Структура репозитория

```
nir/
├── bachelor-thesis/    — актуальное проектирование, решения и доказательства
├── thesis/             — сама пояснительная записка (Markdown → Word)
│   ├── intro.md              — Введение
│   ├── chapter1.md           — Глава 1. Описание и анализ предметной области
│   ├── references.md         — Список использованных источников
│   ├── screenshots/          — скриншоты систем-аналогов для рисунков
│   └── README.md             — конвенции оформления и инструкция pandoc
├── guidelines/         — методички и требования
│   ├── thesis/               — СТО СГАУ по оформлению ВКР
│   └── presentations/        — правила и рекомендации для презентаций
├── examples/           — примеры оформления (чужие ВКР и презентации)
│   ├── theses/               — 4 примера ВКР бакалавра ФИИТ
│   └── presentations/        — 2 примера презентаций (Архарова, Топыркина)
└── CLAUDE.md           — инструкции для ИИ-ассистента по проекту
```
