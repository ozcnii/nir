# Автоматический режим: сбор сам решает встречающиеся задачи

Одна команда запускает сбор и рядом с ним решатель. Если площадка вместо
документа отдаёт задачу (пазл, «разверните картинку», кнопка продолжения), её
решает агент `pi`, а сбор продолжает работу на том же документе.

## Условия

- `pi` установлен и авторизован: `pi auth check --model "$CAPTCHA_MODEL"` → `ready`.
- Модель умеет смотреть изображения. Имя задаётся `CAPTCHA_MODEL`
  (по умолчанию `openai-codex/gpt-6-luna`).
- Для самого сбора — обычные требования: PostgreSQL и переменные окружения
  (`DB_NAME`, `DB_APP_PASSWORD`, `DJANGO_SECRET_KEY`, профиль браузера).

## Запуск

```
python implementation/tools/collect_with_agent.py -- \
    --source cian --region 68 --property-type apartment --deal sale
```

Всё после `--` передаётся команде `collect` без изменений. Каталог брокера —
`--root` (по умолчанию `.broker`), ожидание ответа — `--wait` (по умолчанию 300 с).

Обёртка поднимает `tools/captcha_agent.py`, ждёт секунду, запускает сбор и
гасит решателя по завершении. Если задача не встретится, поведение не
отличается от обычного запуска.

## Что происходит при задаче

```
сбор замечает задачу
  → pending/<id>.json + <id>.png   (признак, адрес, точка начала, снимок)
  → решатель: pi -p с картинкой    (просит измерить сдвиг, а не выполнить действие)
  → answers/<id>.json              ({"action": "drag", "start": [x, y], "dx": N})
  → сбор применяет и читает дальше — без новой навигации
```

До трёх раундов на одну попытку страницы. Если задача осталась — источник
завершается причиной `source_captcha`, ложного успеха нет.

## Без агента

Запуск обычной командой `manage.py collect` без `--captcha-broker` оставляет
прежнее поведение: задача фиксируется как `source_captcha`, прогон завершается
штатно.

## Что проверено

| Задача | Модель | Результат |
|---|---|---|
| Пазл с вырезанным фрагментом | `deepseek-v4.1-flash` | страница разблокировалась |
| «Разверните картинку горизонтально» | `gpt-6-luna` | страница разблокировалась |

Сквозной прогон «сбор + решатель одновременно» пока не подтверждён: задачи не
возникало в момент проверки. Это отложенный пункт S01 в протоколе приёмки.

## Требование к формулировке

Промпт просит **измерить** расстояние по картинке, а действие собирает код.
Модель отказывается, когда её просят выполнить действие на странице проверки, и
отвечает, когда просят измерить сдвиг. Менять формулировку на «сделай действие»
не нужно: это ломает работу, а не улучшает.
