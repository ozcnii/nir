# Чтение карточек Авито

Штатная команда `collect URL` открывает поддержанную публичную карточку Авито
через Playwright. Адаптер читает поля
`window.__staticRouterHydrationData.loaderData["catalog-or-main-or-item"]` и
передаёт в каталог снимок P3. Ключ — номер опубликованной карточки. Проверяются
категория и ID запрошенного и фактического URL, `item.id`, а также `item.url` и
`item.category.slug`, если они опубликованы.

- Проекции покрывают продажу новостройки, вторичной квартиры и дома, месячную
  и суточную аренду квартиры и закрытую карточку. Для продажи комнаты отдельно
  проверены обычная комната, набор и доля. Сохранённая доля отклоняется:
  опубликованная площадь комнаты сама по себе не подтверждает, какая комната
  относится к доле. Явно предложенный набор сохраняется одной единицей и с
  общей площадью, если она опубликована. Число комнат всей квартиры не
  переносится в P3. Противоречащие общие площади одного набора отклоняют снимок.
  Жилая площадь сравнивается отдельно от общей. Проекции Авито подтверждают
  характеристики целого дома, поэтому явно предложенный отдельный блок без
  подтверждённой проекции его собственных характеристик отклоняется.
- Субъект разрешается по опубликованному имени из справочника или по проверенной
  паре города и ID для наблюдавшейся карточки Самары. Активные примеры относятся
  к Самарской области. Координаты читаются из `item.geo.coords`, описание из
  `item.description`, фотографии из опубликованных URL представления `1280x960`.
- Для суточной цены без «от» на карточке `capture_card` принимает метку выдачи
  с той же карточкой. Период и сумма берутся из карточки. При явном «от» в выдаче
  сохраняется `from`, даже когда там указана другая сумма. В одиночном запуске
  без такой метки неподтверждённая суточная цена остаётся `unavailable`.
- Для закрытия прежней публикации нужны тот же публичный ключ, `notFound` и
  явное сообщение «Объявление закрыто.». Команда читает тип сделки из ранее
  сохранённого объявления. Для неизвестного ключа с точным маркером результат
  `not_found`, строки не создаются.

[Проекции](../tests/fixtures/avito-6.1.json) подготовлены из
[полевого аудита 6.1](../../../../bachelor-thesis/evidence/field-audit/avito-pi-2026-11-17/AVITO-CONTRACT-AUDIT.md),
