# Чтение карточек Авито

`avito.read_card` принимает уже открытую Playwright-страницу, исходный публичный URL и время наблюдения от вызывающего кода. Читает поля `window.__staticRouterHydrationData.loaderData["catalog-or-main-or-item"]` и возвращает P3. Навигация, обработка HTTP-статуса, повторы, блокировка запросов медиа и вызов Catalog остаются у вызывающего кода. Коллектор передаёт ссылки галереи, не запрашивая файлы отдельно.

Для активной карточки проверяются категория пути, номер в запрошенном и фактическом URL, публичный `item.id`, а также опубликованные `item.url` и `item.category.slug`, когда они присутствуют. Query и fragment не входят в ключ. Для действительного входного ключа редирект на другой ID или категорию, неподтверждённое состояние и расхождение с `item.id` дают `unavailable`. Ошибочный структурный параметр или неподдержанная предлагаемая единица дают `RejectedCard` до записи.

- Подтверждённые направления 6.1 — продажа новостройки и вторичной квартиры, продажа комнаты и дома, месячная и суточная аренда квартиры. Для доли требуется указание на предлагаемую комнату и её площадь. Количество комнат всей квартиры не переносится в число предлагаемых комнат. Для дома площадь участка переводится в квадратные метры, этаж помещения остаётся неизвестным.
- География активных примеров ограничена Самарской областью. Регион подтверждается опубликованным адресом или, как в карточке новостройки с неполным адресом, проверенной парой Samara и `locationId=653040`. Координаты берутся из `item.geo.coords`. Галерея использует опубликованное представление `1280x960`. Описание берётся из `item.description` с сохранением абзацев.
- Суточную сумму и период определяет карточка. Если её форматированная цена опускает «от», вызывающий код передаёт `listing_price=(url, label)` с тем же публичным ключом и явным суточным периодом. Метка «от» сохраняется при разной сумме в выдаче и карточке. Для цены используется сумма карточки. Одного отсутствия приставки в карточке недостаточно для выдачи `listed`. Без согласованного свидетельства суточная цена имеет статус `unavailable`.
- Для `removed` требуется подтверждённый URL исходной карточки и состояние `notFound` с сообщением «Объявление закрыто.». В закрытой карточке нет активного `item` и сделки. `expected_deal` передаёт вызывающий код по ранее известной публикации. Без сделки или явного сообщения возвращается `unavailable`.

## Данные для воспроизведения

Проекции в `collection/tests/fixtures/avito-6.1.json` основаны на [проверке 6.1](../../../bachelor-thesis/evidence/field-audit/avito-pi-2026-11-17/AVITO-CONTRACT-AUDIT.md), [завершающем проходе](../../../bachelor-thesis/evidence/field-audit/avito-pi-2026-11-17/proxy/FINAL61-STATUS.md) и [наблюдении закрытой карточки](../../../bachelor-thesis/evidence/field-audit/avito-pi-2026-11-17/proxy/REMOVED61-CLOSED.md). По форме подтверждённого buyerItem восстановлены оболочки встроенного состояния. Для дома использованы отобранные опубликованные характеристики и зафиксированная формулировка продажи, для комнаты — отобранные характеристики и цена из сводки. Исходных HTML, сессий, полных текстов продавцов и сетевых запросов в этих проекциях нет. Сохранённые размеры галереи без URL для вторички, комнаты и двух аренд не превращены в ссылки. Отдельные контрпримеры в тесте синтетические.

Гостиничное размещение и неизвестный вид предлагаемой единицы не образуют активный P3. Универсальные признаки гостиничных номеров Авито, новые регионы и направления вне 6.1 этим набором не подтверждены.

18 ноября 2026 в 16:04 UTC обычная навигация по всем семи ссылкам примеров вернула HTTP 429 без встроенной карточки или подтверждённого закрытия. Свежего живого подтверждения работы адаптера нет. Сохранённые проекции воспроизведены в отдельном Chromium без видимого окна.
