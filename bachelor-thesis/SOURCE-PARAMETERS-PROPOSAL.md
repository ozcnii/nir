# 5.1. Параметры источников и запуска

## Источники

Для Авито, Циан и Домклик в составе проекта действует переключатель `sources.enabled`. Он определяет доступность площадки для следующих запусков. Изменение не прерывает текущий сбор и не меняет состояние сохранённых объявлений. Идентификаторы, селекторы, адреса выдач и способы навигации определяет соответствующий адаптер.

## Область сбора

Команда `collect URL` проверяет формат адреса карточки и значение
`sources.enabled` для её площадки до открытия браузера. Режим области
принимает один или несколько `--source`, ID субъекта, вид и сделку.
При продаже квартир можно указать `--segment`, если выбранные источники
поддерживают соответствующий областной маршрут.
[Команда запуска](../implementation/README.md#сбор)

Для полного последовательного обхода параметры задаются из терминала на один запуск. Область включает выбранные включённые источники, регионы из справочника, категории (вторичка, новостройка, комната, дом) и сделки (продажа, аренда на месяц, аренда на сутки). Сочетания ограничены фактически поддержанными маршрутами площадок. Для разных наборов параметров оператор выполняет отдельные последовательные запуски.

Перед полным обходом проверяются непустой выбор, существование выбранных записей и поддержка сочетаний. Выбранная область фиксируется на запуск. От неподдержанного сочетания команда отказывается с причиной. Параметры следующего запуска задаются заново. Постоянным параметром источника остаётся `enabled`.

Таймаут 30 секунд на попытку и один повтор для предусмотренных временных ошибок определены в [4.3](COLLECTION-4.3-PROPOSAL.md). Команда запуска не изменяет эти правила.
