# Независимая проверка схемы по источникам
16 ноября 2026. Проект DB-POINT2-VERIFIED-DRAFT.md; решения владельцем не приняты.

Проверяющий получил проект, дополнительную транскрипцию наблюдений, SOURCE-FIELD-AUDIT.md и §5 НИР. Реализацию, SQL, парсер и работу matching не проверял.

Первичные существенные замечания:
1. Снятие ещё неизвестного ключа не сохраняет временную границу. Старый active затем может быть принят. Исправление: гарантия ограничена существующими строками; not_found явный, предложен последовательный режим без очереди/перекрытия.
2. Видимое «1 гость» не означает доказанные adults=1/children=0. Исправление: guest_count при неизвестном составе; при известном составе сумма не дублируется; неизвестные контексты не выдаются за одинаковые.
3. Для unknown-price не был обязателен deal_type, хотя он нужен для первой строки истории. Исправление: тип сделки обязателен; при невозможности определить — error, при неизвестной сумме price_kind может быть NULL.

Повторная точечная проверка: все три замечания закрыты на уровне проекта и контракта; оставшихся существенных дефектов именно по ним критик не видит. Числовая оценка не запрашивалась и не выдавалась; 10/10 не заявляется.

Предложенные schema tradeoffs сохраняются: отдельного property_id нет; группа через реальную ads.duplicate_of_id; источник не объявляется истиной; партнёр Домклик учитывается отдельно; новые поля и режим исполнения не считаются принятыми.
