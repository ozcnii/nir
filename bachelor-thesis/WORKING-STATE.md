# Текущее состояние ВКР

Действующий проект описан в [сводке](CONSOLIDATED-DESIGN-9.md).
Команды запуска и проверки находятся в [руководстве реализации](../implementation/README.md).

- Сайт и PostgreSQL запускаются через Docker Compose. Сбор запускается отдельной
  командой Django из терминала, итог и ошибки видны в выводе Docker.
- Публичный каталог доступен на `/catalog/`, карточка — на `/properties/<id>/`.
  Список и карточка доступны для чтения в JSON на `/api/properties/` и
  `/api/properties/<id>/`. Источники, регионы и виды недвижимости
  настраиваются в Django admin.
- Команда `collect URL` принимает одну поддержанную карточку Авито, Циан или
  Домклик. Приёмка адаптеров проходит на сохранённых реальных карточках через
  Chromium, команду сбора и PostgreSQL.
- Действующая проверка локального стека охватывает запуск сайта, миграции, права
  app, запись каталога, повтор сбора и остановку процесса по SIGTERM.
- Команда `collect --source … --region …` обходит подтверждённые областные
  направления. Сопоставление применяет правила A/B для квартир, строгий S
  для комнат и адресные правила для домов и блоков. Поддержанные маршруты
  перечислены в [руководстве](../implementation/README.md#сбор). Результаты
  живых проверок и ограничения приведены в [пояснительной записке](../thesis/chapter3.md).
- Текст ВКР находится в [thesis/](../thesis/README.md), кафедральные вопросы —
  в [перечне требований](requirements-closure.md).

Оценка качества и пределы проверок приведены в [аудите реализации](CODE-QUALITY-AUDIT.md).

Оперативные статусы ведутся на [доске GitHub](IMPLEMENTATION-TRACKER.md).
