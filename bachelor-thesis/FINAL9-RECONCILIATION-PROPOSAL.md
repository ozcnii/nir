## 2. Оставшийся выбор: локальная web-команда

В принятом launcher указана web-команда, но HTTP-backend ещё не выбран. Предлагается **для принятой локальной разработки и демонстрации** штатный Django runserver: bind 0.0.0.0:8000, --noreload --insecure, DEBUG=false, обычная многопоточность. Это новый проектный выбор, а не университетское требование или production-развёртывание. Снаружи остаётся loopback; host-порт может быть другим.

Он уже входит в Django; --insecure включает штатную локальную раздачу staticfiles/admin CSS при DEBUG=false, django.contrib.staticfiles и STATIC_URL=/static/. Используется обычный StaticFilesStorage, не ManifestStaticFilesStorage, с которым этот флаг несовместим. Для локального loopback-показа не требуется новый Gunicorn/Uvicorn/Whitenoise-пакет. --noreload исключает второй процесс автоперезагрузчика. Web остаётся ребёнком launcher; реакция на TERM/выход проверяется по принятому lifecycle, а не считается испытанной.

ALLOWED_HOSTS=['127.0.0.1','localhost'] без портов. Web/admin/API работают на одном origin. SECRET_KEY — устойчивое случайное значение в локальном секретном env-файле вне Git, передаваемое при старте; не менять каждый restart. Реальные пароли/ключи не публикуются, env-example содержит явные placeholders. Runtime/migrator credentials не смешиваются. Секреты и конфигурации сейчас не создаются.

DEBUG=false сохраняет уже принятый JSON5.5: штатные пользовательские error-handlers доступны для неизвестного /api/* и необработанного500, выдаётся прежний ErrorResponse без traceback. Не создаётся новый DEBUG-middleware/другая схема ошибок. В будущую проверку F18 включить неизвестный APIпуть и искусственную непредвиденную ошибку ORM/view через реальный локальныйHTTPпрофиль; проверить JSONContent-Type/код/fields и отсутствиеtraceback, одновременно доступностьadminCSS приDEBUGfalse. Это сценарии реализации, не выполненные тесты.

Профиль не меняет CI 8.4: его тестовые серверы/БД не заменяются обязательным Docker/runserver. [Первичные источники](evidence/FINAL9-COMPLETENESS-PRIMARY-SOURCES.md).

Общий ГИА требует отзыв D−7, срок загрузки/формулировки старого бланка не отменяют это требование.

Открыты: индивидуальный план/задание, точные структура/объём/критерии ВКР, актуальный текст нормоконтроля 2019 и кафедральный порядок, персональные реквизиты/кафедральные дополнения. Требования других направлений не переносятся как наши. Это открытая формальная сверка; проект не называется полностью соответствующим всем неизвестным требованиям.
