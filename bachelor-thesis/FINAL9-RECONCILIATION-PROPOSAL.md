## 2. Принятая локальная web-команда

Для локальной разработки и демонстрации сервис `app` запускает штатный Django `runserver --noreload --insecure 0.0.0.0:8000` с `DEBUG=false`. Порт публикуется только на loopback. Сайт, админка и API работают на одном origin. `ALLOWED_HOSTS` включает `127.0.0.1` и `localhost`; `--insecure` позволяет штатному StaticFilesStorage отдавать CSS админки при `DEBUG=false`.

Оператор передаёт `DJANGO_SECRET_KEY` и пароли ролей PostgreSQL через окружение вне Git. Порядок первого запуска и миграций приведён в [руководстве реализации](../implementation/README.md).

F18 проверяет неизвестный API-путь и непредвиденную ошибку через локальный HTTP-профиль. Ответ содержит согласованный JSON ErrorResponse без traceback. CSS админки доступен с `DEBUG=false`. [Первичные источники](evidence/FINAL9-COMPLETENESS-PRIMARY-SOURCES.md).

## 4. Требования: подтверждено и открыто

Программа/ФОС НИР маркированы планом 2023; их состав, алгоритмы/описание ПО, оформление и доклад подтверждены **при применимости этого плана к студенту**. Индивидуальный план/задание и актуальный семестровый шаблон не получены. Общие ГИА/ЭБС устанавливают процедуру, но доступная одностраничная программа ГИА профиля не содержит структуры/критериев ВКР.

Точные источники/пункты: [проверка 9](evidence/FINAL9-COMPLETENESS-PRIMARY-SOURCES.md), [исследование требований](requirements-research.md), [остаток требований](requirements-closure.md). Уточнение ЭБС уже устанавливает cabinet.ssau.ru и форматы doc/tex для проверки и PDF для ЭБС. Рабочий DOCX не объявляется автоматически допустимым форматом загрузки. Общий ГИА требует отзыв D−7, срок загрузки/формулировки старого бланка не отменяют это требование.

Открыты: индивидуальный план/задание, точные структура/объём/критерии ВКР, актуальный текст нормоконтроля 2019 и кафедральный порядок, персональные реквизиты/кафедральные дополнения. Требования других направлений не переносятся как наши. Это открытая формальная сверка; проект не называется полностью соответствующим всем неизвестным требованиям.
