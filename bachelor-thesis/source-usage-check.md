# Условия получения и повторного использования данных Циан и Домклик

Проверено 16 ноября 2026 года. Ниже — фактическое содержание опубликованных документов площадок, не правовое заключение. Техническая доступность выдачи, карточек и фотографий не рассматривается как разрешение на автоматический сбор, накопление базы или публикацию данных.

## Циан

[Правила пользования](https://www.cian.ru/legal-documents/pravila_polzovaniya_sajtom_cian_0/), опубликованная редакция **05.11.2026**, получены прямым HTTP-запросом: **200**, полный HTML 443240 байт. Веб-инструмент на том же адресе получил переход к captcha; это ограничение конкретного инструмента, не содержание правил. Проверен основной текст сохранённого HTML.

- **7.2.3:** запрещены автоматизированные скрипты сбора информации и взаимодействия с сайтом без специального разрешения администрации.
- **7.2.5:** использование сайта вне предоставленных администрацией интерфейсов разрешается лишь в предусмотренных отдельным соглашением случаях.
- **7.2.7:** запрещены неразрешённые программы доступа и извлечение любым способом, копирование, распространение и другое использование материалов базы без согласования.

[Лицензионное соглашение](https://www.cian.ru/legal-documents/licenzionnoe_soglashenie_0/) получено **200**, HTML 349809 байт. В преамбуле объём прав зависит от принятого тарифа. **4.1.3** предусматривает извлечение данных об объектах и последующее использование для личных некоммерческих целей и/или деятельности с недвижимостью с обязательным указанием базы ЦИАН. Вместе с тем **4.2.1** ограничивает коммерческое копирование/распространение базы; **8.1.2–8.1.3** запрещают использование за пределами явно разрешённых случаев без разрешения лицензиара. Наличие 4.1.3 само по себе не подтверждает разрешение на автоматизированный сбор: отдельные ограничения такого способа прямо содержатся в Правилах.

В самих юридических документах найдена ссылка на [условия API](https://www.cian.ru/legal-documents/usloviya_ispolzovaniya_servisa_api_855); документ получен **200**, HTML 207978 байт:

- **1.1–1.2:** для начала использования нужен отдельный API-ключ аккаунта; Циан может отказать в его предоставлении.
- **2.5–2.6:** отдельный функционал может быть платным или ограниченным; само опубликование API не подтверждает бесплатный доступ к требуемой выгрузке.
- **3.3:** использование полученных материалов ограничено тематикой сайта.
- **3.5:** в том числе запрещены автоматизированные скрипты сбора, копирования и распространения через API без предварительного разрешения Циан.

Методы API, доступность выгрузки сторонних объявлений и предоставление ключа в этой проверке не испытывались. Контакт с площадкой, регистрация и оформление подписки не выполнялись.

**Результат:** правила способа автоматического получения установлены; разрешение на автоматический сбор именно для данной ВКР/приложения не получено. Подтверждённый ранее HTTP 200 выдачи, карточки и фото этого не заменяет.

## Домклик

[Наблюдённая официальная ссылка документа](https://api.domclick.ru/storage-public-files/public/v1/files/0195f690-3635-7e00-8723-abd0cdec9be2/link/redirect?source=96b4c872-e332-402c-ad38-44169feae3b7) прямому HTTP-клиенту ответила **403 Forbidden**. Веб-инструмент установил фактический редирект на [PDF пользовательского соглашения](https://public-fs.dmclk.ru/0195f69036357e008723abd0cdec9be2/v18/пользовательское_соглашение_26.10.2026.pdf), но не смог прочитать его. **Именно этот наблюдённый конечный URL**, без подбора иных адресов, получен HTTP-клиентом: **200, application/pdf, 590368 байт, 54 страницы**. На первой странице указано начало действия **26.10.2026**. Содержательный текст извлечён и прочитан; далее номера страниц PDF.

- **1.3.1, с.1:** к незарегистрированным пользователям применяются условия соглашения, кроме положений об использовании сервисов и регистрации. Поэтому отсутствие входа в аккаунт не является установленным исключением из нижеописанных правил базы данных.
- **4.2.1–4.2.2, с.9:** использование/извлечение/копирование/переработка/распространение результатов интеллектуальной деятельности, прямо не разрешённое соглашением, требует предварительного письменного разрешения; запрещено использовать материалы баз сайта для наполнения собственных баз и баз третьих лиц.
- **4.3.1, с.9–10:** обычному пользователю предоставлено право **неавтоматизированного** извлечения сведений об объектах для личных некоммерческих целей и/или совершения сделок с недвижимостью для себя. Упомянутые права на фотографии относятся к принадлежащим Домклик изображениям и личным некоммерческим целям.
- **4.4.1, с.10:** для партнёра также названо неавтоматизированное извлечение; последующее использование в деятельности — на отдельно согласуемых условиях. Партнёрский статус данного проекта не подтверждён.
- **13.1.3, с.27:** автоматизация размещения/копирования/извлечения/изменения/удаления информации запрещена, кроме случаев письменного разрешения Домклик.
- **16.1.1, с.34:** отдельно указаны запреты на программы автоматизации копирования/извлечения, чрезмерную нагрузку и считывание информации программными средствами (скриптами, роботами).
- **4.5.1–4.5.2, с.10:** правила аналитических обзоров допускают использование/цитирование аналитической и статистической информации для указанных целей, в неизменном виде со ссылкой на domclick.ru; при этом сохраняется запрет способов из 13.1.3. Эти положения не подтверждают право создавать собственную базу объявлений.

Публичное API-разрешение для получения и накопления объявлений именно этим проектом в проверенном соглашении не установлено. URL получения юридического PDF — файловый сервис, а не подтверждение открытого API объявлений.

**Результат:** письменное разрешение на автоматизацию для данной ВКР/приложения не получено; текст соглашения также прямо ограничивает наполнение собственной базы. Наблюдённые ранее HTTP 401/Qauth обычного клиента и успешное открытие выдачи/карточки/фото браузером с JavaScript описывают разные технические режимы, но не меняют содержание соглашения.
