Условия использования сервиса API
Для использования сервиса API сайта (далее – «Сервис», «api-интерфейс»), расположенного по адресу http://cian.ru (далее – «Сайт»), владелец аккаунта на сайте cian.ru (далее – «Пользователь») соглашается с настоящими Условиями использования Сервиса и принимает их.

Актуальный список методов API расположен по адресу: http://public-api.cian.ru

1.1. Для начала использования Сервиса Пользователю необходимо обратиться в клиентскую службу Циан посредством email import@cian.ru и запросить уникальный API-ключ для своего аккаунта (ключ авторизации, access key).
1.2. Циан вправе по своему усмотрению отказать любому Пользователю в получении API-ключа и, соответственно, дальнейшего использования Сервиса без какой-либо компенсации или возмещения в связи с этим.
