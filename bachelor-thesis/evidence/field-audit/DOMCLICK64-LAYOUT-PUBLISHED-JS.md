# Домклик: ссылки квартир одной планировки в опубликованном JS

17 ноября 2026. Исследованы только точные scriptURL из dom64-recovery-group-structure.json: main, 92, 152, 794, 845, NewFlatPage. Все шесть curl через SOCKS5 127.0.0.1:10808 дали HTTP200. Браузер не запускался; статус исследования и решения не менялись.

[DOMCLICK64-LAYOUT-PUBLISHED-JS.json](./DOMCLICK64-LAYOUT-PUBLISHED-JS.json) сохраняет точные фрагменты трех существенных файлов, их URL, локальные пути, SHA256 полных тел, размеры и позиции фрагментов.

1. В main функция Oe переводит `flat_id` в `flatId` каждой записи; источник массива — `flats_with_same_layout`, поле модели — `flatsWithSameLayout`.
2. В 794 модуль36995 выбирает flatsWithSameLayout и исключает текущую квартиру по `flatId !== data.id`. Компонент C модальной строки создает `div` с `data-testid="layout-flats-modal-item"`, ценой, этажом, номером квартиры и кнопкой избранного `offerId:e.flatId`. В полном коде этого компонента нет href или onClick перехода. Список передает исходный flat в C. Клик строки не является доказанным способом открыть назначение.
3. В NewFlatPage компонент Es получает `{flatId:n,...}=layout` и строит `const v=`/card/sale__new_flat__${n}${h}``; элемент `a` имеет `href:v`, target `_blank`. Это собственный builder сайта по flatId, а не экстраполяция трех href.
4. Суффикс h вычисляется `(0,yi.A)()`, где `yi=i(14039)`. Модуль14039 из794 берет текущие searchParams через hook `(0,s.ok)()` и возвращает `String(e)?`?${e}`:""`. Поэтому `?to_flats=true` не является жестко зашитым суффиксом builder: он переносится из текущей query, когда там присутствует; переносятся и другие существующие параметры. Самостоятельно утверждать обязательность именно этого суффикса нельзя.
5. В NewFlatPage отдельно существует чтение `to_flats`: при значении `"true"` вызывается scrollToAnchor(FLATS_OF_LAYOUT). Параметр управляет прокруткой к секции, а идентичность квартиры задает flatId в пути.

Точная конструкция опубликованного сайта подтверждена. Доступность всех 13 назначений и эквивалентность состава модалки отображенным ссылочным карточкам этим разбором JS не проверялись. Новые URL конкретных квартир не открывались.
