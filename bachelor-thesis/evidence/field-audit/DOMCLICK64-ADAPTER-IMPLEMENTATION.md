# Адаптер карточек Домклик

Задача [T17C](https://github.com/ozcnii/nir/issues/27) проверяет чтение уже загруженной карточки. Вход и фактический публичный адрес проверяются совместно с идентификатором внутри карточки. Основной сайт, партнёр и Домклик24 формируют один source `domclick` с ключами `/card/<семейство>__<вид>__<ID>`, `/detail/<ID>` и `/card/<UUID>` соответственно. Для неустановленной идентичности результат `unavailable` сохраняет исходный ключ.

| Вход | Привязка к публикации | P3 |
|---|---|---|
| Основной Домклик | `productCard.id`, `dealType`, `offerType`, состояние публикации | Квартира, комната, дом, часть дома или таунхаус. Комната использует `objectInfo.roomArea` и `roomsOffered`, дом — опубликованную площадь участка с проверкой единицы. Снятие требует явной отметки и совпадения ID, сделки и вида в записи со статусом 8. |
| Партнёр | `__NUXT_DATA__` → `data['detail:<ID>']` → `id` | Подтверждённая посуточная квартира. Неподтверждённый тариф имеет статус `unavailable`. Номера и неоднозначные виды предложения пропускаются до передачи в каталог. |
| Домклик24 | Inline `window.__SSR_STATE__` → `inventory.searchData.id` | Подтверждённая посуточная квартира. Суточная цена читается только у позиции выдачи с тем же ключом, пустыми датами, полем «1 гость» и явной суточной ценой. Для фото используются URL основной галереи, сверенные с перечнем карточки. |
| Новостройка основного сайта | Историческое подтверждение `shell.flatDetails.data.id` | Публичный ключ распознаётся. Полный P3 остаётся недоступен до проверки исходных путей физических полей и основной галереи. |

Команда `collect URL` использует общее выполнение через Django. `read_card` передаёт снимок P3 без записи. Для Домклик24 `read_daily_listing_quote` читает цену и контекст из соответствующей позиции выдачи. При неполном списке фото или неподтверждённой цене соответствующее поле получает `unavailable`.

Часть дома требует опубликованного адреса с обозначением блока или секции и её номером. Если продавец предлагает долю самого блока, номер блока не подтверждает самостоятельность этой доли. Для таунхауса полный опубликованный составной номер `7/2` сохраняется без интерпретации дроби при подтверждении из структурированного адреса карточки. Один слеш в строке адреса недостаточен. У дуплекса 2080868633 сопоставимая опубликованная площадь расходится с основным полем, поэтому снимок отклоняется. Комнатная площадь и число комнат берутся из `roomArea` и `roomsOffered`. Текстовый конфликт учитывается, когда площадь однозначно относится к предлагаемой комнате. Нулевое число комнат допускается при явном подтверждении студии.

## Проверка

Проверки выполнены на `5d14a4ff0c0f0390a8aedbed90ea00f41e90640d`. В отдельном проекте `bash implementation/tests/compose.sh` прошли 44 теста Django и 13 проверок каталога на PostgreSQL. Сквозной тест через Playwright и команду Django подтвердил одну публикацию и одну строку цены после повтора. Карточка с чужим ID не изменила уже сохранённую запись. [GitHub Actions](https://github.com/ozcnii/nir/actions/runs/44428199689)

В обычном headless-контексте Playwright 1.65.2 / MS Edge на Windows через `ssh qq` основной Домклик вернул HTTP 401 для карточки новостройки 2072470664. Другие семейства этого хоста в ходе той же пробы пропущены после отказа. Полный набор физических полей новостройки и опубликованные URL непустой галереи основного сайта остаются непроверенными.

Партнёрская карточка и Домклик24 открылись по HTTP 200. Снимки P3 кратковременно переданы по SSH в отдельную проверочную БД. Каждый снимок был принят методом каталога под ограниченной ролью `app`. После исходного приёма и повтора с более новым временем каждой карточке соответствуют одна публикация и один объект.

| Карточка | Сохранённый результат |
|---|---|
| [/detail/2252883](https://domclick.sutochno.ru/detail/2252883) | 23,00 м², 1 комната, 14 URL фото, история цены пуста |
| [/card/1999c326-4f66-410d-8ea7-0d01a6e8af4e](https://24.domclick.ru/card/1999c326-4f66-410d-8ea7-0d01a6e8af4e) | 36,00 м², 1 комната, 19 URL фото, одна запись 3910,00 ₽ `listed` |

Цена Домклик24 получена из выдачи для того же ключа с пустыми датами и одним гостем. При прямом открытии карточка дала `price=unavailable`. Повтор не продублировал историю. Проверочные контейнеры, сети, тома и временные копии снимков удалены. Живая приёмка семейств основного сайта остаётся открытой. [Выдача Домклик24](https://24.domclick.ru/samara)
