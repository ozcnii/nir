# Адаптер карточек Домклик

Задача [T17C](https://github.com/ozcnii/nir/issues/27) проверяет чтение уже загруженной карточки. Вход и фактический публичный адрес проверяются совместно с идентификатором внутри карточки. Основной сайт, партнёр и Домклик24 формируют один source `domclick` с ключами `/card/<семейство>__<вид>__<ID>`, `/detail/<ID>` и `/card/<UUID>` соответственно. Для неустановленной идентичности результат `unavailable` сохраняет исходный ключ.

| Вход | Привязка к публикации | P3 |
|---|---|---|
| Основной Домклик | `productCard.id`, `dealType`, `offerType`, состояние публикации | Квартира, комната, дом, часть дома или таунхаус. Комната использует `objectInfo.roomArea` и `roomsOffered`, дом — опубликованную площадь участка с проверкой единицы. Снятие требует явной отметки и совпадения ID, сделки и вида в записи со статусом 8. |
| Партнёр | `__NUXT_DATA__` → `data['detail:<ID>']` → `id` | Подтверждённая посуточная квартира. Неподтверждённый тариф имеет статус `unavailable`. Номера и неоднозначные виды предложения пропускаются до передачи в каталог. |
| Домклик24 | Inline `window.__SSR_STATE__` → `inventory.searchData.id` | Подтверждённая посуточная квартира. Суточная цена читается только у позиции выдачи с тем же ключом, пустыми датами, полем «1 гость» и явной суточной ценой. Для фото используются URL основной галереи, сверенные с перечнем карточки. |
| Новостройка основного сайта | Историческое подтверждение `shell.flatDetails.data.id` | Публичный ключ распознаётся. Полный P3 остаётся недоступен до проверки исходных путей физических полей и основной галереи. |

`read_card` возвращает P3 без записи в каталог. Для Домклик24 `read_daily_listing_quote` читает контекст и цену позиции, после чего тот же наблюдаемый результат можно передать `read_card`. При неполном списке фото или неподтверждённой цене возвращается `unavailable` соответствующего поля.

Часть дома требует опубликованного адреса с обозначением блока или секции и её номером. Для таунхауса сохраняется также составной номер дома из опубликованного адреса, как в карточке 1885120006 с номером 7/2. Общий номер строения без отдельного обозначения и явно неподходящие виды предложения отклоняются. В сопоставимом случае 2080868633 опубликованная в описании площадь дуплекса расходится с основным значением, поэтому карточка отклоняется. Нулевое число комнат сохраняется только для квартиры с явным заголовком студии.

## Проверка

Playwright Chromium в чистом headless-контексте на Mac получил HTTP 200 для [партнёра](https://domclick.sutochno.ru/detail/2252883), [карточки Домклик24](https://24.domclick.ru/card/1999c326-4f66-410d-8ea7-0d01a6e8af4e) и [её городской выдачи](https://24.domclick.ru/samara). Партнёр вернул квартиру 23,00 м², 14 фото и `price=unavailable`. Домклик24 вернул квартиру 36,00 м², 19 фото и 3910,00 ₽ `listed` из указанной выдачи с пустыми датами и одним гостем. Адреса, координаты и описание получены из основных данных карточек.

На проверенных страницах основного Домклик получен HTTP 401 без состояния карточки. Отдельная штатная headless-навигация на Windows к опубликованной новостройке 2072470664 также вернула HTTP 401. Для основного сайта replay сохраняет отдельно адресуемый таунхаус 1885120006, отклоняет части дома 1525510020 и 2081525526, а также здание общежития 1695973117. Извлечение непустой галереи основного сайта, полные поля новостроек и живой приём в PostgreSQL остаются непроверенными. Синтетические контрпримеры покрывают чужой ID/семейство, гостиничную единицу и неразрешённую единицу площади до передачи в каталог.
