# Адаптер карточек Домклик

Задача [T17C](https://github.com/ozcnii/nir/issues/27) проверяет чтение уже загруженной карточки. Вход и фактический публичный адрес проверяются совместно с идентификатором внутри карточки. Основной сайт, партнёр и Домклик24 формируют один source `domclick` с ключами `/card/<семейство>__<вид>__<ID>`, `/detail/<ID>` и `/card/<UUID>` соответственно. Для неустановленной идентичности результат `unavailable` сохраняет исходный ключ.

| Вход | Привязка к публикации | P3 |
|---|---|---|
| Основной Домклик | `productCard.id`, `dealType`, `offerType`, состояние публикации | Квартира, комната, дом, часть дома или таунхаус. Комната использует `objectInfo.roomArea` и `roomsOffered`, дом — опубликованную площадь участка с проверкой единицы. Снятие требует статуса 8 для совпавших ID, вида и сделки и точной видимой отметки в основном содержимом. При отсутствии ID независимое подтверждение не получено. |
| Партнёр | `__NUXT_DATA__` → `data['detail:<ID>']` → `id` | Подтверждённая посуточная квартира. Неподтверждённый тариф имеет статус `unavailable`. Номера и неоднозначные виды предложения пропускаются до передачи в каталог. |
| Домклик24 | Inline `window.__SSR_STATE__` → `inventory.searchData.id` | Подтверждённая посуточная квартира. Суточная цена читается у позиции основной выдачи после сверки видимого списка с `serp.ids`, при пустых датах, поле «1 гость» и явной суточной цене. Для фото используются URL основной галереи, сверенные с перечнем карточки. |
| Новостройка основного сайта | `shell.flatDetails.data.id`, `shell.isDeletedFlat` | Активный P3 строится при подтверждённом субъекте. Применяются опубликованные поля конкретной квартиры. Непустая галерея без полных опубликованных URL остаётся недоступной. |

Команда `collect URL` использует общее выполнение через Django. `read_card` передаёт снимок P3 без записи. Для Домклик24 `read_daily_listing_quote` читает цену и контекст из соответствующей позиции выдачи. При неполном списке фото или неподтверждённой цене соответствующее поле получает `unavailable`.

Часть дома требует опубликованного адреса с обозначением блока или секции и её номером. Если продавец предлагает долю самого блока, номер блока не подтверждает самостоятельность этой доли. Для таунхауса полный опубликованный составной номер `7/2` сохраняется без интерпретации дроби при подтверждении из структурированного адреса карточки. Один слеш в строке адреса недостаточен. У дуплекса 2080868633 сопоставимая опубликованная площадь расходится с основным полем, поэтому снимок отклоняется. Комнатная площадь и число комнат берутся из `roomArea` и `roomsOffered`. Явное противоречие в составе комнат или выделении доли отклоняет карточку. Для набора сохраняется только явно указанная общая площадь предложенных комнат. Площади дома, отдельного блока и участка сверяются в собственной области. Нулевое число комнат допускается при явном подтверждении студии.

## Поля новостройки и основной выдачи

Опубликованные скрипты новостройки связывают `shell.flatDetails.data` с `objectInfo`, `flatInfo`, `address`, `building.floors` и `media.photos`. На конкретной карточке ранее наблюдались площадь 54,3 м², 2 комнаты, этаж 2/17, квартира № 121. Селектор `priceInfo.currentPrice` используется основным выводом цены с явным знаком ₽. Контролируемая проверка воспроизводит эти поля и проверяет границу географии. Субъект из общей географии страницы применим, когда её GUID совпадает с GUID адреса карточки. Живой проход с таким совпадением в текущем окружении не подтверждён. [Перечень опубликованных скриптов](DOMCLICK64-LAYOUT-PUBLISHED-JS.json), [Выборка карточек](embedded-card-matrix-2026-11-17.json)

В сохранённой HTML-выдаче Домклик24 на странице без дат были 36 первичных ключей в `serp.ids` и 32 отрисованные строки. Опубликованный компонент SerpPage отрисовывает основной виртуальный список в `section.QrLw3`, контейнер `.N05bk`. Каждая строка получает `data-index`, по которому компонент берёт ключ первичной выдачи. При воспроизведении сохранённого HTML без сетевых запросов позиция с тем же ключом вернула 3910 ₽ за сутки. Неопределённая роль контейнера, несовпавший индекс или несколько подходящих строк оставляют цену недоступной. [Поля первичной выдачи](DOMCLICK64-FINAL-PRIMARY-SUPPLEMENT.md), [опубликованный SerpPage](https://statics.dmclk.ru/confer/static/3662/1558678/28b4413/js/SerpPage_e3f450432255784ab834.js)

## Проверка исходного прохода

Проверки выполнены на `5d14a4ff0c0f0390a8aedbed90ea00f41e90640d`. В отдельном проекте `bash implementation/tests/compose.sh` прошли 44 теста Django и 13 проверок каталога на PostgreSQL. Сквозной тест через Playwright и команду Django подтвердил одну публикацию и одну строку цены после повтора. Карточка с чужим ID не изменила уже сохранённую запись. [GitHub Actions](https://github.com/ozcnii/nir/actions/runs/44428199689)

В обычном headless-контексте Playwright 1.65.2 / MS Edge на Windows через `ssh qq` основной Домклик вернул HTTP 401 для карточки новостройки 2072470664. Другие семейства этого хоста в ходе той же пробы пропущены после отказа. Живое сопоставление полей новостройки и непустая галерея основного сайта остаются непроверенными.

Партнёрская карточка и Домклик24 открылись по HTTP 200. Снимки P3 кратковременно переданы по SSH в отдельную проверочную БД. Каждый снимок был принят методом каталога под ограниченной ролью `app`. После исходного приёма и повтора с более новым временем каждой карточке соответствуют одна публикация и один объект.

|---|---|

| [/card/1999c326-4f66-410d-8ea7-0d01a6e8af4e](https://24.domclick.ru/card/1999c326-4f66-410d-8ea7-0d01a6e8af4e) | 36,00 м², 1 комната, 19 URL фото, одна запись 3910,00 ₽ `listed` |

Проверочные контейнеры, сети, тома и временные копии снимков удалены. Живая приёмка семейств основного сайта остаётся открытой. [Выдача Домклик24](https://24.domclick.ru/samara)
