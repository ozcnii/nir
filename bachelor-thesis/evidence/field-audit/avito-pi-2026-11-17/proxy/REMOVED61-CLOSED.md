# 6.1 Авито: снятое объявление подтверждено

17 ноября 2026. **6.1 закрыт на уровне проверки источника и проектирования. Прикладной код не писался.** Владелец прямо принял правило from, затем поручил подтвердить реальное снятие, чтобы закрыть6.1.

## Принятое правило суточной цены

Для наблюдавшегося случая Авито у одной публикации выдача явно содержит «от», а formattedPrice основной карточки опускает приставку. Сохраняется price_kind=from; сумму и период берём из основной карточки. Разница места извлечения не создаёт from→listed и ложную запись истории. Это не означает from для любой суточной цены всех источников. Новых полей дат/гостей/валюты не добавлено.

URL: https://www.avito.ru/krasnodar/kvartiry/1-k._kvartira_316_m_49_et._8417769121

Публичный номер8417769121. Реальная ссылка найдена в опубликованном примере автора https://apify.com/amitaviv/avito-scraper ; его данные служили только поиску ссылки. HTTP200 не означает active; title404/type=notFound/редирект/429 сами по себе не означают removed. Не устанавливаем причину «продано», дату снятия или универсальную таблицу числовых statusId.

## Применение уже принятого контракта

Конверт: source_code=avito, external_id="8417769121", state=removed, observed_at — время нашего наблюдения. state — существующее временное поле сообщения, не новая колонка БД.

Для уже известного объявления, с учётом принятого порядка времени: ads.is_active=false, observed_at обновляется; недвижимость, property_id, характеристики, фото и история цены сохраняются. Для неизвестного ключа: not_found без создания пустой квартиры/публикации. Это ранее принятыйP4, не новая схема и не исполненная запись в БД.
