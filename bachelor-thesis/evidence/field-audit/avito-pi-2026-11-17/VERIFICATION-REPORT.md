# Avito: фактическая проверка через Pi Playwright

**Итог: частичный успех.** В изолированном контексте прошёл первую видимую проверку Avito, получил реальную страницу квартир Самары и открыл первое объявление. При переходе по фактической ссылке на дома Avito снова вернул HTTP 429; повторная проверка осталась на «Повторите попытку». На этом остановился — без цикла повторов и без изменений сети/браузера.

## Хронология

- **17.11.2026, 00:47:39** — исходный `https://www.avito.ru/samara/kvartiry/prodam` вернул HTTP 429, заголовок «Страница не загрузилась из-за проблем с IP».
- **00:47:46** — нажата видимая кнопка «Пройти проверку». Открылся пазл Geetest. Несколько UI-перетаскиваний были отклонены; последующая горизонтальная попытка примерно на 120 CSS px прошла. Запросы `firewallCaptcha/verify`, `firewallPow/get` и `firewallPow/verify` получили 200. Сначала страница показала «Проверка пройдена, перенаправление…» и «Нужна небольшая проверка браузера», затем загрузился реальный список.
- **К 00:51:06** — отобразилась страница покупки квартир в Самаре (заголовок «Купить квартиру в Самаре», 7 170 результатов). Первую видимую карточку открыл через её фактическую ссылку.
- **00:54:49** — нажата фактическая ссылка футера «Дома, дачи, коттеджи». Новый запрос вернул HTTP 429 и потребовал повторной проверки.
- **00:55:00–00:55:20** — нажал видимую кнопку проверки; одна попытка с видимым слайдером завершилась сообщением «Повторите попытку». Страница домов оставалась заблокированной. Дальнейшие попытки прекращены.
- Перед завершением закрыл только принадлежащие этому MCP-контексту вкладки через `browser_close`; итог MCP: «No open tabs».

Времена — локальные метки вывода браузера; часовой пояс не установлен.

### Отображение в контракте

- Физические характеристики и география (`region`, `address`, координатные источники, тип квартиры, комнаты, площади, этаж) относятся к объекту недвижимости.
- Цена и поля публикации (описание — только длина, фото-URL, статус, дата, сделка) относятся к объявлению. Цена — сумма `14766700` RUB плюс `listed_from=false`; период продажи не задан.
- `source_code=avito` — константа адаптера, не поле Avito. Для `external_id` источником служат фактические `item.id`/URL, поскольку опубликованное `item.externalId` равно `null`.
- Новые поля БД не предлагались.
