# Домклик24: сохранение первичных доказательств 6.4

17 ноября 2026. Read-only исследование; код приложения и продуктовые решения не менялись.

## Опубликованный JavaScript

[DOMCLICK64-PUBLISHED-JS-FRAGMENTS.json](./DOMCLICK64-PUBLISHED-JS-FRAGMENTS.json) сохраняет точные подстроки реально существовавших локальных main, 755 и 902 той же опубликованной сборки. Для каждого исходного файла сохранены полный sourceURL, путь локального тела, размер, SHA256 полного тела и позиции фрагментов в строке UTF-16. Фрагменты содержат SEARCH `/search`, разбор `location_id`/`adt`, builder `location_id:t.guid,adt:t.adults.toString()`, GET geoObject/autocomplete и вызов autocomplete с `{name:e,limit:6}`. Код не реконструирован; новых запросов за JS не делалось. Исходные URL взяты из уже зафиксированной первичной цепочки в DOMCLICK64-FINAL-PRIMARY-SUPPLEMENT.md; HTTPстатус старой загрузки JS не восстановлен из байтов.

## Целевой HTTP capture категорий

[DOMCLICK64-CATEGORY-HTTP-CAPTURE-2.json](./DOMCLICK64-CATEGORY-HTTP-CAPTURE-2.json) содержит четыре новые пробы: отдельный свежий goto исходного адреса перед каждой категорией, собственный headless Chromium через SOCKS5 127.0.0.1:10808. Реальный input `name="filters.categories"` получал element.click(), затем существующая форма requestSubmit(). Даты не выбирались; исходные response JSON не подменялись. Ожидание ответа `/api/offers/ad/v1` не фильтровало HTTPстатус.

| География | Категория | HTTP | total / count / ids | Геополе после формы |
|---|---|---|---|---|
| Самара | house | 200 | 0 / 0 / [] | Самара |
| Самара | room | 200 | 0 / 0 / [] | Самара |
| Самарская область | house | 200 | 0 / 0 / [] | Самарская область |
| Самарская область | room | 200 | 0 / 0 / [] | Самарская область |

В JSON сохранены фактические responseURL/query, статус ответа, выбранные поля тела, URL страницы до/после, состояния категории и поля географии, дат и гостей. Во всех query отсутствуют даты, adults=1, limit=36, offset=0. Городской locationGuid `6369cbfc-1f06-4574-adba-82f4dc42c0f7`, областной `321b0daa-da95-4ce5-81b3-a7ab62d89d19`. После формы городские URL `/samara?categories=house|room`; областные сохраняют `location_id`, `adt=1` и выбранную категорию. Поле дат пустое, гости «1 гость».

Это успешные транспортные ответы с пустым результатом конкретных четырех контекстов, а не положительное обнаружение домов/комнат, не доказательство отсутствия таких объектов вообще и не полный сбор. Обычный видимый поток открытия фильтров без дат здесь не заявляется: использован существующий обработчик формы через DOM.

Сетевых сбоев в сохраненных четырех пробах не было. Первый capture сохранил HTTP/query/нули, но пропустил безымянное геополе из-за слишком узкого селектора; выполнен один исправленный capture этих же четырех контекстов с геополем и пустыми датами. Таблица и JSON относятся к исправленному capture. Собственные браузеры закрыты в finally. Основной Домклик и его ограничения не проверялись; WORKING, DECISIONS и чеклист не изменялись.
