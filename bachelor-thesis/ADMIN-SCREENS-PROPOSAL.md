# 5.4. Вход, источники и справочники

## Вход и доступ

Вход и выход выполняются через штатный Django admin. Сервер проверяет права при прямом переходе и при выполнении действий. Неавторизованный посетитель перенаправляется на вход. Пользователь без права на действие получает отказ. Самостоятельная регистрация и отдельные предметные роли в БД не предусмотрены.

Каталог и карточка недвижимости доступны для просмотра без регистрации в рамках принятого интерфейса. Выход из Django admin и закрытие вкладки не прерывают работу отдельной команды сбора.

## Источники

Для поддержанных источников показывается понятная подпись по коду. В базе хранится переключатель `sources.enabled`. Менять идентификатор, маршруты и селекторы источника через Django admin нельзя.

Значение `enabled` проверяется при старте. Смена значения действует на последующие запуски. Сохранённые объявления от этого не снимаются и не удаляются. Для остановки текущего сбора используется сигнал его процессу в терминале. [Параметры запуска](SOURCE-PARAMETERS-PROPOSAL.md)

## Справочники

Регионы и виды недвижимости ведутся через штатные списки и формы Django admin. Пустые и повторные имена запрещены. Стабильный ID сохраняет ссылки на запись, изменение подписи не меняет её предметный смысл. Новый элемент справочника сам по себе не создаёт маршрут сбора.

Используемую запись защищают внешние ключи. Во время сбора сервер отклоняет одиночное и массовое удаление, включая прямые запросы. Интерфейс поясняет причину недоступности действия. Проверка блокировки и удаление выполняются в одной транзакции с учётом гонки запуска и удаления. Если команда сбора получила блокировку первой, удаление отклоняется. Если удаление завершилось первым, новый полный обход сверяет выбранные справочники при запуске. [Синхронизация](PROCESS-LIFECYCLE-PROPOSAL.md)

## Работа со сбором

Сбор запускается отдельной командой Django из терминала. Результаты и ошибки видны в выводе контейнера. Ограничение одного активного сбора действует на уровне PostgreSQL. [Запуск и остановка](PROCESS-LIFECYCLE-PROPOSAL.md), [Вывод и повторный запуск](JOURNAL-STATE-RESTART-PROPOSAL.md)

На странице `/admin/` доступны формы поддержанных источников, регионов
и видов недвижимости. Причина отказа в удалении отображается в разделе
справочника. При отказе запись и журнал административных удалений
сохраняют прежнее состояние. Доступ к каталогу и карточке проверяется
совместно с публичными экранами.
