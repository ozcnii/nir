## Контрольный эксперимент с блокировкой

В контрольной копии на базе предыдущего интерфейса приёма снимка запись блокирует найденное объявление штатным
`select_for_update()`. Сессионная блокировка команды в этой копии
отсутствует. Тесты используют реальный PostgreSQL и разные подключения.

| Сценарий | Копия с блокировкой строк | Один ключ PostgreSQL |
| --- | --- | --- |
| Первый снимок одного объявления одновременно из двух сессий | Ошибка уникальности | Создаётся одна публикация и одна запись цены. Повтор получает `ignored` |
| Первые объявления одной квартиры от разных площадок | Разные `property_id` | Два объявления с одним `property_id` |
| Второй запуск при занятом сборе | Допущен | Отказ |
| Удаление неиспользуемого справочника во время сбора | Допущено | Отказ. После освобождения ключа удаление проходит |

Общий ключ использует штатные функции PostgreSQL. Одна команда может
удерживать его во время запроса страницы без открытой транзакции. Короткая
транзакция записи использует тот же ключ. Отдельная сессия с записью ждёт
завершения сбора. [Блокировки PostgreSQL](https://www.postgresql.org/docs/17/explicit-locking.html#ADVISORY-LOCKS)
· [Блокировка строк Django](https://docs.djangoproject.com/en/5.2/ref/models/querysets/#select-for-update)

## Доказательства и границы

- Ruff, форматирование и mypy прошли для 43 файлов Python. Compose проверил
  HTTP, миграции, 24 теста Django, 13 сценариев PostgreSQL и 24 ожидаемых
  отказа записи под ролью `app`.
- Сбор через Chromium проверен на сохранённой карточке Циан. Подтверждены
  повтор после HTTP 503, запаздывающий оффер на странице с заглушкой
  и чужим ID, повтор без новой цены, отказы `collect` до Chromium и
  освобождение ключа после SIGTERM. Реальный SIGTERM послан до запроса
  карточки. Отдельный тест проверяет приоритет остановки при ошибке разбора.
- Порядок ошибок P3 проверен на конфликте типа сделки, старом снимке,
  неизвестном регионе и ошибочных ссылках галереи. Пограничные ссылки
  объявления сопоставлены с правилами базы `4f928f2`.
- Полный сценарий согласованного чтения F15, административные маршруты
  F22, живая проверка источников и GitHub CI этим прогоном не подтверждены.
  Полные тексты реальной пары F07 отсутствуют в проверяемых данных.
  Удаление проверено через функцию каталога. Согласованный административный
  маршрут пока отсутствует. Сценарий независимого запаздывания необязательного
  JSON-LD отдельно не воспроизводился.
