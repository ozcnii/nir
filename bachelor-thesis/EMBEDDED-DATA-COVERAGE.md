17 ноября 2026. По прямому запросу владельца проверено получение структурированных данных из кода страниц Циан и Домклик. Официальные API не использовались. Авито отложен. Прикладной код не написан, схема БД и закрытые алгоритмы не менялись.

## Результат

Повторно открыты 14 реальных карточек: на каждой площадке по примеру вторичной продажи, новостройки, комнаты, дома, месячной аренды, суточной аренды и снятого объявления. Суточный маршрут Домклик — уже известный партнёрский, source_code остаётся domclick. Во всех 14 найдены встроенные структурированные данные, однако одинакового объекта для всех страниц нет и наличие всех необязательных полей не гарантируется.

## Существенные различия

- Комната Домклик: objectInfo.area=68.8 — вся квартира, roomArea=9.2 — продаваемая комната; rooms=3 — вся квартира, roomsOffered=1 — предлагаемая единица. Циан различает category=roomSale / roomsForSaleCount; offerType=flat сам по себе не означает продажу целой квартиры.
- Циан суточно: bargainTerms.priceType=all при price=3000, но offerData.offerPrice явно «от3 000 ₽/сут.». Нельзя трактовать all как наш listed: это не признак точности предложения. Категория dailyFlatRent различает сутки, тогда как dealType=rent этого не делает.
- Суточный партнёр: свойства rooms=1/area=23/floor=4/max_floor=5, координаты, описание125символов и14фото доступны. objectBasePrice содержит1800RUB, но objectPrice=null, priceObject={}. JSON-LD AggregateOffer.lowPrice=1800 не является расчётом выбранного проживания. Итог бронирования в этой проверке не получен; контекстный total не подставляем в принятую историю рублевой цены. Базовую цену не объявляем автоматически точным дневным тарифом без подтверждения смысла.
- Новостройка Домклик:54.3м²,№121/подъезд2,этаж2/17,8304840руб. Индивидуальное objectInfo.description=null, complex.description не подставляется. media.photos содержит1относительный путь; комплексные фото не становятся индивидуальными. Полный опубликованный URL для такого пути следует брать из фактического DOM основной галереи, не придумывая домен/размерCDN. В этой матрице записан сам исходный путь, свежий полный URL не утверждается.
- Дом Домклик: в иерархии адреса несколько уровней населённых пунктов/СНТ. Сохранять иерархию компонентов; короткая строка «Самара» не даёт права потерять СНТ или придумать дом. Частичный адрес Циан330631159 остаётся без дома даже при наличии координат.
- Область и координаты доступны в состоянии проверенных карточек обеих площадок, включая текущую Циан330631159. Это уточняет старую проверку только метатегов. В Домклик subject выбирается по типу province/subkind=region, не по любому province (федеральный округ тоже имеет province).
- Циан снятая карточка: status=deleted, есть явная отметка. Домклик снятый дом: status=8 и явное «Объявление снято с размещения»; не угадываем остальные числовые статусы. Unicode-пробел внутри отметки требует сжатия пробелов перед текстовой проверкой. Наличие старой суммы/характеристик не делает карточку активной; применяется уже принятый контракт removed.
- SSR Домклик — сериализованный JS-объект с undefined, не строго чистый JSON. Nuxt — массив ссылок на значения. Нужен разбор соответствующего формата без eval и без смешения undefined с явным null; конкретная готовая библиотека не выбрана и не установлена этой проверкой.

## Предложение для проекта

Оставить уже принятый Playwright для загрузки. Источник значений — встроенное состояние с проверенным разбором каждого семейства; DOM — для конкретных недостающих значений/полных опубликованных фотоссылок с установленной семантикой. Не делать универсальный сбор всех чисел/картинок страницы. Два принятых адаптера collection.cian/domclick сохраняются; три формы Домклик — ветки его адаптера, не новые модули/источники/таблицы.

Эта детализация получения полей — предложение, пока владелец её не принял. Метод браузерной загрузки4.1 остаётся принятым. Пункт4.2 в целом ещё не принят,4.3 не закрыт.
