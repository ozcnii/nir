Это проверенный неуспех прямого запроса, а не доказательство невозможности API в браузерной сессии; повтор API в браузерной сессии не выполнялся.

В конфигурации карточки есть https://api.cian.ru/offer-card/ , но один baseURL не подтверждает публичныйGETчужойкарточки. Изученные archive/deleteметоды не вызывались.
