**ПРЕДЛОЖЕНИЕ, НЕ ПРИНЯТО.** 18 ноября 2026. 8.1–8.4 приняты и закрыты. Точные версии ниже — предлагаемый единый исходный набор по опубликованным требованиям и матрицам авторов. ## 2. Проверенная цепочка совместимости

1. Django 5.2 поддерживает Python 3.13; PyPI Django 5.2.19 требует Python>=3.10. Django требует PostgreSQL>=14 и psycopg>=3.1.8, выбранные 17.12/3.3.9 удовлетворяют этим условиям.
2. В README именно tag django-stubs 5.2.9, не текущего master, указаны Django 5.2 (полная), mypy 1.13–1.19, Python 3.10–3.13. PyPI extra уточняет mypy<1.20. Поэтому пара 5.2.9/1.19.1 выбрана сознательно; номера stubs не обязаны совпадать с patch Django.
3. Для остальных инструментов сверены Requires-Python, наличие стабильного не-yanked выпуска и опубликованные зависимости. Psycopg-binary, mypy и Playwright имеют wheels для нужных платформ. Это ещё не полное разрешение всех транзитивных зависимостей.
4. Python.org 3.13.18 публикует исходники, а не новые официальные binary installers. В manifest uv 0.13.9 найдены готовые python-build-standalone 3.13.18+20261110 для Darwin ARM64 и Linux x86-64 GNU; это сборки Astral, не установщики Python.org. Установка не выполнялась.
5. Локально проверено только текущее окружение компьютера: macOS 27.0.1 ARM64. Для CI предлагаем ubuntu-24.04 x86-64; эта платформа входит в опубликованные Playwright system requirements. Mac runtime также подпадает под macOS14+ в текущей документации; наличие wheel и соответствие требованиям не выдаются за реальный browser smoke.

## 3. Фиксация среды CI

Один профиль без матрицы всех версий: ubuntu-24.04, CPython 3.13.18, PostgreSQL 17.12, Chromium из Playwright 1.65.2. ubuntu-24.04 — метка обслуживаемого GitHub runner, не неизменяемый образ всей ОС; system packages могут обновляться. Для PostgreSQL предлагаем официальный postgres:17.12-bookworm с проверенным manifest digest sha256:40865bc877a289da75963d97d72b59633f639fc5af7a4e856bfa3714cae5b536, доступны Linux amd64/arm64. Digest зафиксирован как опубликованный артефакт, образ не загружался и не запускался.

Старые npm-инструменты иллюстраций ВКР не обновляются этим предложением.

## 4. Условия применения и обновлений

После принятия набора и отдельного разрешения реализации: подготовить одну среду; получить uv.lock и проверить разрешение зависимостей; проверить реальные версии Python/драйвера/PostgreSQL/браузера; выполнить согласованный профиль 8.2/8.4, загрузку Django-plugin, миграции и целевые ORM/transaction/LiveServer+Playwright сценарии. Наличие metadata не заменяет эти проверки. Если реальная несовместимость обнаружится, показать конкретный конфликт и предложить узкую замену, не ослаблять strict и не менять стек молча.

Точные pins — исходная воспроизводимая точка, не вечный запрет исправлений безопасности. Новые security/minor/major обновления показываются владельцу с причиной и совместимостью; после принятия меняются согласованно и проверяются по затронутому риску. Автоматические major updates/latest и отдельный апгрейд mypy вне матрицы stubs не предлагаются. Реальная установка и создание конфигов этой задачей не разрешены.
