## Публикация материалов

- ВGit сохраняются проектные документы, история решений/отзывы, нормативные источники и выбранные текстовые/JSON-доказательства.
- `requirements/disciplines-assessment-2023.pdf` хранится черезGitLFS из-за размера. Для полной локальной копии после клонирования нужны установленныйGitLFS и `git lfs pull`.
- Аудио/расшифровки преподавателя, сырые журналы/сессии/HTML и диагностические снимки браузера сохраняются локально и исключены [правиламиGit](.gitignore). Они не публикуются в открытом репозитории. [LOCAL-ONLY.json](LOCAL-ONLY.json) содержит перечень иSHA256, но не содержимое этих файлов и не является их резервной копией. Исторические ссылки на такие сырые материалы доступны только локально; выбранные доказательства опубликованы отдельно.
- Прежний локальный путь `/Users/qq/Documents/ssau/bachelor-thesis` сохранен как ссылка на эту папку; новые правки по нему попадают в этот же Git-репозиторий, второй рабочей копии нет.
